# page load extension

Панель в Chrome DevTools. Показывает, сколько грузится страница или один микрофронт — до элемента, который вы сами указали.

В отчёте — время до готовности, трафик и LCP. Всё остаётся в браузере и никуда не отправляется.

## Установка

Нужен Chrome 118 или новее.

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. Откройте сайт, затем DevTools → **page load extension**.

## Замер

1. Выберите область: **Вся страница** или **Микрофронт / модуль**.
2. Укажите CSS-селектор элемента, который появляется, когда загрузка закончена. Например, `#app[data-ready="true"]`.
3. Нажмите **Сохранить и обновить**.

Для микрофронта добавьте фрагменты URL его файлов, по одному на строку.

Пока идёт замер загрузки, не кликайте и не прокручивайте страницу.

## С чего начать отсчёт

- **Сохранить и обновить** — с начала загрузки страницы.
- **Ждать действие** — с клика, Enter или пробела. Ожидание в замер не входит. Можно ограничить действие конкретной кнопкой или ссылкой.

## Серия и пресеты

- **10 обновлений** — десять одинаковых загрузок со средним, минимумом и максимумом.
- Пресет сохраняет настройки, чтобы не вводить их заново.
- **Скачать отчёт** сохраняет результат в JSON.
